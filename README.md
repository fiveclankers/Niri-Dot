# Niri-Dot

Personal config backup for the [Niri](https://github.com/YaLTeR/niri) scrollable-tiling Wayland compositor.

## What is in here

- `niri/`: Keybinds, layout rules, and window rules
- `fish/`: Shell functions and aliases
- `ghostty/`, `kitty/`, `alacritty/`: Terminal configs
- `noctalia/`: Shell/polkit theme
- `.spicetify/`: Spotify tweaks
- `Pictures/Wallpapers/`: Wallpaper stash

## Quick notes

These are my personal configs from when I was testing Niri. Take whatever looks useful, but review keybinds and display configs before copying anything over.
